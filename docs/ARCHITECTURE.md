# NetraSonar Architecture

## Project Structure

```
NetraSonar/
├── src/                    - All source code
├── config/                 - Configuration files
├── data/                   - Data and metadata
├── deployment/             - Backend, frontend, Docker
├── docs/                   - Documentation
├── tests/                  - Unit and integration tests
├── scripts/                - Utility scripts
├── reports/                - Model reports and metrics
└── .github/                - CI/CD pipelines
```
