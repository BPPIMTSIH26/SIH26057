# DRISHTI SSS Dataset

This directory contains the verified DRISHTI Side Scan Sonar dataset. 
It consists of underwater sonar images of 5 classes:
- Crab Pot
- Submarine Pipeline
- Shipwreck
- Ghost Net
- Mine Cylinder

The dataset is partitioned into `train`, `valid`, and `test` splits following the YOLO formatting structure.

For full verification details, see `DATASET_VERIFICATION.json`.
