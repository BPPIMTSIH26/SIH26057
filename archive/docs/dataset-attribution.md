# Dataset Attribution

The S.A.G.A.R. platform relies on the open-source dataset for side-scan sonar imagery:

- **Repository:** `narayan-nkj/sagar-sss` (Hugging Face)
- **License:** CC-BY-SA-4.0
- **Size:** 5,205 tiles (training, validation, testing splits)
- **Format:** YOLOv8 formatted bounding box labels.

We acknowledge the contributors and maintainers of this dataset for enabling robust AI development in the marine technology sector.
